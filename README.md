# Onyx BioPartners — Website

Marketing site for **Onyx BioPartners**. Built with vanilla HTML/CSS/JS, bundled with [Vite](https://vitejs.dev/), and deployed on Netlify.

---

## Requirements

Node.js 20+ (see `.nvmrc`).

---

## Local development

```bash
npm install     # install dependencies
npm run dev     # start dev server at http://localhost:5173
```
